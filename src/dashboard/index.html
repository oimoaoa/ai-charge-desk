Data definitions

숫자 기준

달러 · 한화 표기

비용은 달러($)가 기본, 원화(₩)는 괄호로 표기한다. $ = estimated token cost(토큰 단가 환산 추정치)로 구독 청구액이 아니며, ₩은 그 $ 값을 USD→KRW 환율로 환산한 참고값이다(환율 실패 시 마지막 값 + "옛 환율" 표기).

사용률 (quota %)

Used percent (몇 % 썼나)는 비용(cost)과 다른 값이다. Claude·Codex 사용률(현재세션·주간·Fable)은 실시간 사용량 API(read-only)에서 확보한다. 조회 못 하면 임의로 만들지 않고 마지막 성공값(오래됨) 또는 미표시로 둔다.

리셋 시각

리셋은 "N시간 후"만이 아니라 KST 실제 시각(예: 오후 4:59)과 상대시간을 같이 보여준다.

집계 기간

비용 집계는 오늘 / 주간(월요일~일요일) / 이번 달(매월 1일~)로 나뉜다. 각 값 옆에 시작~종료 시각(KST)을 표기한다. 사용률 %의 리셋 창은 구독 리셋 주기라 이 비용 집계 창과 다를 수 있다.
